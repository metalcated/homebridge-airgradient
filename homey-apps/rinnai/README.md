# Rinnai Control-R

Reserved for a future Homey app. No driver or working integration is included yet.

The inspected Homebridge installation uses `homebridge-rinnai-controlr@1.0.26` from https://github.com/dustindclark/homebridge-rinnai-controlr, declared Apache-2.0. It communicates through AWS authentication, GraphQL, and device-shadow APIs. Existing Homebridge configuration and credentials remain on the server.
